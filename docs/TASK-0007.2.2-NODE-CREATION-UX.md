# Task-0007.2.2 — Node Creation UX

## User-facing behavior

- Right-click `Entities` to create a new root 2D or UI node.
- Right-click any node to create a child node.
- Empty NGVGE node trees show three entry buttons: `2D Node`, `User Interface Node`, and disabled `3D Node`.
- Node creation uses a searchable modal container.
- 3D is visible as a planned category but remains disabled until the 3D runtime is available.

## Registry integration

Node types now expose a `family` field:

- `2d`
- `ui`
- `3d`

Plugin-provided node types can appear automatically in the corresponding creation browser by declaring `family` in their node type registration.

## Built-in UI node

`ngvge.control` is provided as the first UI-family node type. It stores position, size, anchor, and visibility data. Runtime UI rendering is outside this task.
