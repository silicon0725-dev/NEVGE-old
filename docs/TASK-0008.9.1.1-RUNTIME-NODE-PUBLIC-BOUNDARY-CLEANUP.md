# TASK 0008.9.1.1 — Runtime Node Public Boundary Cleanup

Status: Implemented / Required before 0008.9.2  
Parent: `0008.9.1 Runtime Node API Freeze`  
Scene System version: `0.8.9.1`  
Runtime Node persistent format: `1`  
Runtime Node public API version: `1.2`

## Purpose

Task 0008.9.1 established a frozen snapshot API and controlled mutation entry points. This cleanup removes the remaining JavaScript-host assumptions before the public boundary is treated as portable.

The task does not change Node identity, component persistence, lifecycle semantics or the project format. It separates four authority levels that were previously exposed through one service object:

```text
Portable Runtime Node Query Capability
Portable Runtime Node Mutation Capability
Restricted Node Type Registration Host
Internal Runtime Node Persistence Controller
```

## Capability split

### `ngvge.runtime-node-model@1.2`

The ordinary Runtime Node capability contains only:

- portable snapshot queries;
- portable semantic mutations;
- a local event-subscription wrapper;
- temporary compatibility aliases;
- frozen contract metadata.

It does not expose:

```text
importState
persistState
synchronizeScenes
registerNodeType
traverse
dispose
RuntimeNodeGraph
RuntimeNodeTypeRegistry
```

### `ngvge.runtime-node-type-registration@1`

This is a restricted Runtime Host capability used by the Module Host and extension infrastructure. It separates:

```text
NodeTypeDescriptor
    portable typeId, version, scope, schema and ownership data

Local Provider Binding
    JavaScript ctor/create, future native factory or WASM provider
```

A descriptor may cross a protocol boundary. A local provider function and its unregister closure may not.

### `ngvge.runtime-node-persistence-controller@1`

This controller owns:

```text
exportState
importState
persistState
synchronizeScenes
```

It remains internal to Scene System and is not published through the module capability registry. Scratch Compatibility receives the controller by direct host injection because it participates in project migration and rollback.

### `ngvge.runtime-node-local-host@1`

This local-only host owns:

```text
traverse(visitor)
dispose()
```

Neither method is part of the portable Runtime Node contract.

## Portable query replacement for traversal

The callback-based local traversal API is replaced at the public boundary by:

```js
nodeModel.querySubtree({
    rootNodeId,
    order: 'pre', // pre | post | breadth
    maxDepth: null,
    includeRoot: true
});
```

The result is deeply frozen portable data:

```js
{
    query: {
        rootNodeId,
        order,
        maxDepth,
        includeRoot
    },
    nodes: [
        {node: NodeSnapshot, depth: 0},
        {node: NodeSnapshot, depth: 1}
    ]
}
```

Project Explorer uses `querySubtree()` and no longer requires a JavaScript visitor callback from the Runtime Node capability.

## Provisional mutation result

Until ARC-C001 provides full transaction rollback, every portable mutation returns:

```js
{
    applied: boolean,
    persisted: boolean,
    snapshot: PortableSnapshot | null,
    error: PortableError | null
}
```

The three meaningful outcomes are:

```text
applied: false, persisted: false
Runtime state was not changed.

applied: true, persisted: true
Runtime state and project persistence both succeeded.

applied: true, persisted: false
Runtime state changed, but the persistence write failed.
The caller must not repeat the mutation as though nothing happened.
```

API shape is frozen after this task. Mutation transaction semantics remain explicitly provisional until the ARC-C001 Transaction Gate supplies atomic commit and rollback.

First-party local integrations that require persisted success use `assertRuntimeNodeMutationResult()`. The helper throws a structured error carrying the original `mutationResult`, including whether the mutation was already applied.

## Compatibility aliases

The following aliases remain on the public object for legacy consumers:

| Alias | Canonical replacement |
| --- | --- |
| `getNode` | `getNodeSnapshot` |
| `getComponent` | `getComponentSnapshot` |
| `patchComponentData` | `patchComponent` |
| `renameNode` | `patchNode` |

NGVGE first-party source must not call them. `scripts/check-runtime-node-public-boundary.js` enforces this rule in `src/`, excluding only the explicit compatibility and service-definition boundary.

## Exact public surface gate

`Reflect.ownKeys(runtimeNodeModel)` must match the frozen `publicSurfaceKeys` recorded by `getApiContract()`.

An undeclared method, hidden symbol, getter, setter or host controller added to the capability is an architecture failure. The only permitted surface consists of:

```text
Contract methods
Compatibility aliases
apiVersion
capabilityId
version
nodeScopes
```

## Portable data gate

`validatePortableData()` and `assertPortableData()` reject:

```text
Function
Promise
Symbol / BigInt
Class instance
Map / Set
DOM or Scratch runtime object
Backend handle object
Circular reference
Non-finite number
Accessor or non-enumerable data property
Sparse array or custom array property
```

Portable data and Persistent DTO validation share strict plain-data mechanics, but remain distinct contracts:

```text
Portable Data
IPC / WebSocket / WASM / Native Bridge payload suitability

Persistent Data
Long-term project storage suitability
```

## Native Bridge suitability

Each method in the machine-readable API contract declares:

```text
portability
acceptsCallback
returnsFunction
argumentsSerializable
resultSerializable
```

Every method marked `portable` must:

- accept serializable payloads;
- return serializable payloads;
- require no callback or constructor;
- return no function or local object identity;
- expose no Runtime, Scratch or backend instance.

All arguments supplied to a method marked `portable` are validated before the handler runs. A non-portable mutation argument produces `applied: false`; a non-portable query argument is rejected before any Runtime access.

`subscribe()` is a local-only wrapper for future Protocol Event Subscription semantics. It is not classified as a query.

## First-party migrations

The following first-party integrations now use only canonical methods:

- Project Inspector uses `patchNode()` instead of `renameNode()`;
- Project Explorer uses `patchNode()` and `querySubtree()`;
- Scratch Sprite Adapter receives a portable model capability plus restricted host controllers;
- Scene System publishes only the portable model and restricted type-registration capabilities;
- persistence/synchronization remains private to the Scene System host.

## Non-goals

This task does not implement:

- transaction rollback;
- protocol transport or IPC;
- module permission enforcement for restricted capabilities;
- lifecycle state-machine changes;
- component schema registration;
- Native Kernel factories.

Those remain the responsibility of later 0008.9 tasks and ARC-C001.
