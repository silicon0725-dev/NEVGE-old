# Task-0007.3.2 — Extension Center UI Redesign

## Goal

Replace the legacy source-list presentation with a first-class NGVGE Extension Center while keeping every pre-existing online marketplace and loading path available.

## Information architecture

- Discover
  - Home
  - Installed
- NGVGE Ecosystem
  - NGVGE Official
  - Community (reserved)
- Compatibility
  - All compatibility
  - Official Scratch
  - 02Engine Legacy
  - Other
- Online Markets
  - All online sources
  - TurboWarp
  - PenguinMod
  - AstraEditor
  - Mist
  - SharkPool
  - CCW
- Load custom extension

## UI changes

- Dedicated Extension Center component and CSS module.
- Product header with global search, sorting and batch actions.
- NGVGE overview panel on the Home page.
- Grouped ecosystem navigation instead of one flat `Sources` list.
- New extension cards showing source, native/compatible status, installed state, author and explicit action.
- Favorites and batch selection remain available.
- CCW recommendation and pagination controls remain available when CCW is selected.
- Disabled entries cannot be opened, and author links no longer trigger card installation.
- The custom extension loader remains a dedicated sidebar action instead of a duplicate gallery card.

## Compatibility

No remote URL or extension loading path was removed. The UI continues to use the Task-0007.3.1 Manifest v2 and Source Registry adapters.

## Deferred

- Plugin detail page.
- Permission approval dialog.
- Community repository connection.
- Update discovery and version comparison.
- Source enable/disable management.
