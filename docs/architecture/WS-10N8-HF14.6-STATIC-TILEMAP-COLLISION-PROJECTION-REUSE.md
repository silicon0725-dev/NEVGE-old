# WS-10N8-HF14.6 | Static TileMap Collision Projection Reuse

Status: Implemented / machine verification pending.

HF14.6 treats TileMap collision projections as static runtime geometry until TileMap, TileSet, or a Transform in the TileMap hierarchy changes. Viewport AABB collision queries reuse bounded frozen projection snapshots. Tile collision templates are prepared once per TileSet revision and projected through the TileMap hierarchy as one point batch. Stable no-overlap debug wrappers are reused.

Authority remains unchanged: TileMap sparse chunks and TileSet resources remain NGVGE semantic/persistent authority; caches are transient execution storage only.
