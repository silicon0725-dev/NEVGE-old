# WS-10N8-HF14.8 | Passive Target / Toolbox / Mouse Layout Containment

Status: IMPLEMENTED / MACHINE VERIFIED / BROWSER RE-TEST REQUIRED

HF14.8 addresses the remaining Scratch continuous-motion editor overhead after HF14.7.
It does not reduce Scratch VM execution, mouse sampling, Scratch → NGVGE Transform projection,
Collider2D semantics, or Physics2D execution.

## Changes

1. Full Scratch target-list Redux synchronization is sampled at 250 ms while scripts are actively running.
   Project Inspector telemetry keeps its separate 83 ms policy.
2. Blockly flyout `move/glide/set x/y` default fields are not rewritten while scripts are running.
   One final position sync occurs on `PROJECT_RUN_STOP`.
3. Stage mouse input reuses a cached canvas rect during high-frequency mouse movement.
   The rect is refreshed on resize/scroll/component update and at most every 250 ms during motion.
4. New profiler categories: `Scratch Toolbox Position Sync` and `Scratch Mouse Input / Layout`.

These are presentation/compatibility policies only. Runtime authority is unchanged.
