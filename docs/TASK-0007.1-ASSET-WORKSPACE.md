# Task-0007.1 — Independent Asset Workspace and Layout Refactor

## Goal

Move the full Asset Manager out of Project Explorer and rebuild it as a dedicated, resizable workspace.

## Result

- Project Explorer keeps a compact Assets provider summary and an `Open Asset Workspace` command.
- Asset Workspace is a separate draggable, resizable, minimizable window.
- Window position and size use the existing 02Engine window-state persistence system.
- The Asset Manager layout is divided into:
  - left navigation and folders;
  - center search and asset browser;
  - right preview, metadata, actions, and references.
- High-frequency commands remain in a single top toolbar.
- Asset history remains independent from Inspector property history.
- No changes were made to the Task-0007 asset database or SB3 metadata format.

## Compatibility

The change is editor-only. Existing Task-0006 and Task-0007 project metadata remains readable without migration.
