## Accepted post-freeze debt

### Git working-tree schema debt

The working-tree format still does not preserve information that its exporter never wrote:

1. standalone workspace comments;
2. custom extension URLs;
3. monitor state;
4. every original target ordering/layer metadata field such as `layerOrder`;
5. a true MD5 asset-identity fallback on platforms without the expected MD5 implementation.

These are future schema/versioning work, not silent-loss regressions in the data currently covered by the R3 contract.

### Scoped TypeScript trust boundaries

The strict TypeScript gate remains intentionally scoped to `src/addons/addons/02agent`:

- legacy JavaScript imports are allowed and not checked (`allowJs: true`, `checkJs: false`);
- Scratch VM / Blockly / PluginContext internals are modeled minimally rather than fully typed;
- React 16 runtime remains paired with a newer locked React type graph plus a narrow compatibility augmentation.

### Scene performance debt

Scene System V2.1 is functionally stable and browser-validated. Further profiling of very large node trees, snapshot capture/restore latency, React reconciliation, and long-session cache/GC behavior is explicitly post-freeze performance work unless a future measurement demonstrates correctness-impacting stalls or leaks.

### Build-toolchain modernization debt

The production build remains on webpack 4 / legacy Terser-era infrastructure. R10 diagnostic runs show active compilation rather than a deadlock, but the toolchain is a future modernization target independent of the frozen NGVGE semantic architecture.
