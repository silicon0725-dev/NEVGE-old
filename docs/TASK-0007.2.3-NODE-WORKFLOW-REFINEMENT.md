# Task-0007.2.3 — Node Workflow Refinement

## User-visible goal

Refine the NES Studio node workflow around a Godot-style scene tree:

- The Create New Node dialog is rendered above every floating editor window.
- A blank project starts with only the required Scratch Stage backend and no demo sprites or scripts.
- The empty scene tree offers three root presets: 2D Node, User Interface Node, and a disabled 3D Node placeholder.
- Right-click creation uses one Add Node / Add Child Node command and opens a searchable node picker containing every registered node type.
- Node context menus provide common tree operations such as rename, duplicate, enable/disable, reparent, expand/collapse, and delete.

## Non-goals

- No 3D runtime or Node3D implementation.
- No physical collision solving or physics simulation.
- No replacement of Scratch VM's mandatory Stage target.
- No online node marketplace.

## Data model

The node persistence schema remains compatible with Task-0007.2. The only database capability added is deep subtree duplication. No stored project migration is required.

## Editor integration

- Node dialogs and context menus use a document-body portal to escape floating-window stacking contexts.
- The Create New Node dialog can browse all node families when no family filter is supplied.
- Empty root presets are shown only when there are no custom NGVGE nodes and no Scratch sprite targets.
- Existing Stage/Sprite target nodes remain protected from rename, duplicate, disable, reparent, and delete operations.

## Blank project behavior

The built-in default project now contains:

- one Stage target;
- one blank backdrop required by Scratch VM;
- zero sprites;
- zero scripts;
- zero variables, lists, broadcasts, and sounds.

The legacy `override-default-project.sb3` and `02engine.svg` demo assets are no longer loaded.

## Compatibility

- Existing SB3 projects still load normally.
- Existing NGVGE node metadata remains unchanged.
- The blank built-in project affects only newly opened default sessions.
- User-defined custom default projects are not modified.

## Acceptance checklist

1. Start NES Studio with no project loaded and confirm there are no demo sprites.
2. Confirm the empty node area shows 2D, User Interface, and disabled 3D root presets.
3. Create a 2D root and confirm the presets disappear.
4. Right-click a node and choose Add Child Node.
5. Confirm the node picker is above Stage, Asset Workspace, Inspector, and other floating windows.
6. Search for Collider2D and create it as a child.
7. Test Rename, Duplicate, Enable/Disable, Reparent to Scene Root, Expand/Collapse, and Delete.
8. Save and reload the project and confirm the hierarchy remains intact.
