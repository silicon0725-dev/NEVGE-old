# TASK 0008.9.1 — Runtime Node API Freeze

Status: Implemented; portable boundary finalized by `0008.9.1.1`  
Parent: `0008.9 Runtime Node Model Freeze`  
Scene System version: `0.8.9.1`  
Runtime Node persistent format: `1`  
Runtime Node public API version: `1.2`

## Scope

This task freezes the Runtime Node API shape without changing component schemas, lifecycle semantics or the persistent Runtime Node format.

The initial `1.1` implementation established deeply frozen snapshots and controlled mutation entry points. Task `0008.9.1.1` completed the freeze by separating portable API, restricted host registration, internal persistence control and local traversal.

## Canonical query boundary

The portable capability returns deeply frozen plain-data snapshots only:

- `getNodeSnapshot(nodeId)`
- `getComponentSnapshot(nodeId, componentId)`
- `getSceneSnapshot(sceneId)`
- `getGraphSnapshot()`
- `querySubtree(query)`
- `listNodes()` / `getChildren()` / `getParent()`

No query returns a mutable `RuntimeNode`, `RuntimeComponent`, `RuntimeNodeGraph`, registry instance, callback-bound iterator or backend object.

## Canonical mutation boundary

- `createNode`
- `destroyNode`
- `duplicateNode`
- `patchNode`
- `patchNodeMetadata`
- `setNodeEnabled`
- `setParent`
- `reorderChild`
- `detachNode`
- `addComponent`
- `removeComponent`
- `patchComponent`
- `setComponentData`
- `setComponentEnabled`

Every portable mutation returns a frozen result containing `applied`, `persisted`, `snapshot` and `error`.

The API shape is frozen. Atomic transaction and rollback semantics remain provisional until ARC-C001.

## Capability ownership

```text
ngvge.runtime-node-model@1.2
Portable query and mutation boundary

ngvge.runtime-node-type-registration@1
Restricted descriptor registration and local provider binding

ngvge.runtime-node-persistence-controller@1
Scene System internal; not published as an ordinary module capability

ngvge.runtime-node-local-host@1
Local traversal and disposal only
```

## Compatibility aliases

The following names remain temporarily available for legacy consumers:

| Alias | Canonical replacement |
| --- | --- |
| `getNode` | `getNodeSnapshot` |
| `getComponent` | `getComponentSnapshot` |
| `patchComponentData` | `patchComponent` |
| `renameNode` | `patchNode` |

NGVGE first-party code is prohibited from calling these aliases. The architecture gate scans `src/` and fails when a new dependency is introduced.

## Freeze gates

- exact `Reflect.ownKeys` surface match;
- portable query/result validation;
- Native Bridge suitability descriptors;
- no callback or factory in portable methods;
- no persistence controller on the ordinary capability;
- no mutable Runtime or backend instance in query results;
- first-party compatibility-alias ban.

## Explicit non-goals

- lifecycle state-machine changes;
- component schema registry;
- complete graph validation;
- protocol command transport;
- atomic transaction rollback;
- removal of the legacy compatibility facade used by old plugins and test harnesses.

Those remain in later 0008.9 subtasks and ARC-C001.
