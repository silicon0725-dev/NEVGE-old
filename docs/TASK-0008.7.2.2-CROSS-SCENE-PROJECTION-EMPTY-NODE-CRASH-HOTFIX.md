# Task 0008.7.2.2 — Cross-Scene Projection & Empty-Node Crash Hotfix

## Reported behavior

- A Sprite created in Scene B was absent from the Scene B branch after returning to Scene A.
- A childless `Scratch Sprite · Bound` row displayed an expand arrow.
- Clicking that row crashed Project Explorer with `ReferenceError: visitVisibleNode is not defined`.

## Fixed contract

```text
Active Scene Sprite   -> Scratch Sprite · Bound
Inactive Scene Sprite -> Scratch Sprite · offline
No real child nodes   -> no disclosure arrow
Row activation        -> never invokes an undefined traversal function
```

## Implementation

The adapter now hydrates its complete project index from all scene sidecars and creates any missing inactive Runtime adapter nodes. Scene transitions are bracketed by Scene Runtime events so VM Target reconstruction cannot be assigned to the old active scene. Project Explorer normalizes JSX children before deciding whether a row is expandable and uses one correctly scoped compatibility traversal function.
